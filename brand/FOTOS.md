# Fotos del sitio

Coloca cada foto en `src/assets/fotos/` con **exactamente** este nombre (jpg, png o webp).
Mientras falte, el sitio muestra un placeholder dorado con el nombre esperado.
Astro las optimiza solas (AVIF/WebP, varios tamaños): sube el original en buena calidad, mínimo 2000 px de ancho para las de fondo.

| Archivo | Dónde aparece | Formato sugerido |
|---|---|---|
| `hero` | Fondo del hero "España desde dentro" | Horizontal, ≥ 2400 px, zona inferior izquierda oscura o despejada |
| `collage-1` | Collage inclinado, sección "Cada viaje se diseña…" | Vertical 4:5 |
| `collage-2` | Collage inclinado | Cuadrada |
| `collage-3` | Collage inclinado | Vertical 3:4 |
| `para-ti` | Sección "No es para todos" | Vertical 4:5 |
| `ruta-vinedos` | Tarjeta y hero de "España entre viñedos" | Vertical 4:5 (también se usa de fondo horizontal) |
| `ruta-norte` | Tarjeta y hero de "Sabores del norte" | Igual |
| `ruta-medieval` | Tarjeta y hero de "España medieval" | Igual |
| `cierre` | Fondo del cierre "¿Estás pensando en ir o volver a España?" | Horizontal, ≥ 2400 px |

Tratamiento: tonos cálidos de hora dorada (como la presentación de marca), sin blanco y negro.
